## Topics Covered

- **Deep Learning basics** — neurons, activation functions, loss functions, optimization (SGD, ADAM)
- **MLP** — forward/backward propagation, training dynamics, regularization
- **CNN** — convolutions, pooling, modern architectures
- **Preprocessing** — feature scaling, normalization, data preparation
- **RNN** — sequence modeling, vanishing gradients, LSTM/GRU motivation
- **Transformers** — self-attention, multi-head attention, positional encoding, GPT-style language models
- **GAN** — adversarial training, DCGAN / conditional GANs
- **TinyML** — running ML models on resource-constrained edge devices
